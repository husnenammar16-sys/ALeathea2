أريد منك بناء بوت Discord احترافي بالكامل لسيرفر اسمه Alythia.

أنا مبتدئ جدًا في البرمجة، لذلك أريد منك أن تنشئ المشروع والكود والملفات المطلوبة بنفسك، وأن تجعل المشروع سهل التعديل والتطوير لاحقًا.

التقنية

* استخدم Python.
* استخدم مكتبة discord.py الحديثة.
* استخدم Slash Commands مثل /help و/ticket.
* اجعل جميع رسائل البوت وواجهته باللغة العربية.
* استخدم Unicode وUTF-8 بشكل صحيح.
* لا تنشئ Web Dashboard حاليًا.
* لا تستخدم OpenAI API أو أي API مدفوع حاليًا.
* استخدم ملف .env أو Replit Secrets لحفظ Discord Bot Token بشكل آمن.
* لا تضع الـ Token داخل الكود.
* أنشئ requirements.txt.
* أنشئ README.md يشرح لي بطريقة بسيطة جدًا كيف أشغل البوت وأضيفه إلى السيرفر.

هوية البوت

اسم البوت: Alythia
لغة البوت: العربية
ستايل الرسائل: فخم، عصري، بسيط ومرتب.
استخدم Embeds بشكل احترافي مع ألوان متناسقة مع هوية سيرفر Alythia.

الأنظمة المطلوبة

1. نظام المعلومات

أضف:

* /help لعرض جميع أوامر البوت.
* /ping لعرض سرعة استجابة البوت.
* /server لعرض معلومات السيرفر.
* /user لعرض معلومات العضو.
* /avatar لعرض صورة العضو.

2. نظام الترحيب

عند دخول عضو جديد:

* أرسل رسالة ترحيب جميلة داخل قناة يتم تحديدها من الإدارة.
* اعرض اسم العضو.
* اعرض عدد أعضاء السيرفر.
* استخدم Embed مرتب.
* اجعل الإدارة قادرة على تحديد قناة الترحيب.

الأوامر:

* /welcome setup
* /welcome disable

3. نظام التذاكر

أنشئ نظام Tickets احترافي.

الأمر:
/ticket setup

يقوم بإنشاء رسالة Embed تحتوي على زر:
🎫 فتح تذكرة

عند الضغط:

* ينشئ البوت قناة خاصة بالتذكرة.
* العضو وصلاحيات الإدارة فقط يستطيعون رؤيتها.
* أرسل رسالة ترحيبية داخل التذكرة.
* أضف زر إغلاق التذكرة.
* عند الإغلاق، اطلب تأكيدًا قبل حذف القناة.

اجعل النظام يدعم أنواع التذاكر مثل:

* الدعم العام
* الشكاوى
* طلب مساعدة
* الشراء

واجعل الإدارة قادرة على تحديد Category الخاصة بالتذاكر.

4. نظام الإدارة

أضف أوامر Slash للإدارة:

* /ban
* /kick
* /timeout
* /untimeout
* /warn
* /clear
* /lock
* /unlock

كل أمر يجب أن يتحقق من صلاحيات العضو قبل تنفيذه.

اجعل رسائل الأخطاء واضحة بالعربي، مثل:
“ليس لديك صلاحية لاستخدام هذا الأمر.”

5. نظام التحذيرات

أنشئ نظام Warns باستخدام قاعدة بيانات.

عند استخدام:
/warn @member السبب

يتم:

* تسجيل التحذير.
* إرسال رسالة للعضو.
* تسجيل العملية في قناة Logs.
* إظهار عدد تحذيرات العضو.

أضف:
/warnings @member

لعرض تحذيرات العضو.

وأضف:
/clearwarnings @member

لحذف تحذيرات العضو، للإدارة فقط.

6. نظام Logs

أنشئ نظام Logs يسجل الأحداث المهمة، مثل:

* دخول عضو.
* خروج عضو.
* Ban.
* Kick.
* Timeout.
* Warn.
* حذف رسالة.
* تعديل رسالة.
* فتح تذكرة.
* إغلاق تذكرة.

الأمر:
/logs setup

حتى تستطيع الإدارة تحديد قناة اللوقز.

7. نظام الرتب

أضف نظام Auto Role.

الأمر:
/autorole setup @role

عند دخول عضو جديد، يحصل تلقائيًا على الرتبة المحددة.

وأضف:
/autorole disable

8. نظام الاقتراحات

أنشئ نظام Suggestions.

الأمر:
/suggest setup

يقوم بإعداد قناة الاقتراحات.

يمكن للعضو إرسال اقتراح، ويظهر في Embed مع أزرار:
👍 قبول
👎 رفض

ويتم تسجيل نتيجة الاقتراح.

9. نظام التفاعل

أضف Reaction/Buttons بسيطة للتفاعل مع الأعضاء، مثل:

* التصويت.
* الاقتراحات.
* التذاكر.

10. قاعدة البيانات

استخدم SQLite في البداية لأنها بسيطة ولا تحتاج خدمة خارجية.

خزن فيها:

* إعدادات كل سيرفر.
* قناة الترحيب.
* قناة Logs.
* إعدادات التذاكر.
* Category التذاكر.
* رتبة Auto Role.
* تحذيرات الأعضاء.
* إعدادات الاقتراحات.

اجعل قاعدة البيانات تعمل تلقائيًا عند تشغيل البوت.

نظام الصلاحيات

اجعل الأوامر الحساسة متاحة فقط لمن لديهم الصلاحيات المناسبة.

لا تسمح لأي عضو عادي باستخدام:

* Ban
* Kick
* Timeout
* Warn
* Clear
* Lock
* Unlock
* إعداد التذاكر
* إعداد Logs
* إعداد Welcome
* إعداد Auto Role

جودة الكود

أريد المشروع منظمًا وليس ملفًا واحدًا ضخمًا.

قسم المشروع إلى ملفات أو Cogs، مثل:

bot.py

cogs/

* general.py
* moderation.py
* welcome.py
* tickets.py
* logs.py
* warnings.py
* suggestions.py
* autorole.py

واستخدم:

* Error Handling
* Logging
* Environment Variables
* SQLite
* Modular Code

مهم جدًا

قبل إنهاء المشروع:

1. تأكد أن الكود لا يحتوي على Discord Token مكتوب مباشرة.
2. تأكد أن جميع المكتبات المطلوبة موجودة في requirements.txt.
3. تأكد أن Slash Commands يتم تسجيلها بشكل صحيح.
4. أصلح أي أخطاء في الكود قبل تشغيل المشروع.
5. شغل البوت واختبره.
6. إذا ظهر خطأ، أصلحه بنفسك.
7. لا تحذف أي نظام مطلوب.
8. لا تضف Web Dashboard حاليًا.
9. لا تضف OpenAI API حاليًا.
10. اجعل كل شيء باللغة العربية.

طريقة الشرح لي

بعد إنشاء المشروع، لا تفترض أن لدي خبرة بالبرمجة.

اشرح لي:

1. أين أضع Discord Bot Token في Replit Secrets.
2. ما اسم الـ Secret الذي يجب أن أستخدمه.
3. كيف أشغل البوت.
4. كيف أدعو البوت إلى سيرفري.
5. ما الصلاحيات التي يحتاجها البوت.
6. كيف أستخدم كل أمر.
7. كيف أعدل الإعدادات.

إذا كان هناك شيء يحتاج مني أن أفعله داخل Discord Developer Portal، أعطني التعليمات خطوة بخطوة وبطريقة مناسبة لشخص يستخدم الآيفون.

ابدأ الآن بإنشاء المشروع والكود والملفات المطلوبة، ثم اختبر المشروع وأصلح أي أخطاء تظهر.
